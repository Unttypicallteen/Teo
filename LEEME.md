# Proyecto Teo · página web

## Verla en localhost
1. Instala Node.js (versión 18 o más nueva) desde https://nodejs.org si no lo tienes.
2. Abre una terminal en esta carpeta (TEO).
3. La primera vez: `npm install`
4. Cada vez: `npm run dev`

Se abre sola en http://localhost:5173. Para detenerla: Ctrl + C en la terminal.

Necesita internet para la letra y el visor 3D (se cargan de un CDN).

## Archivos
- `index.html` — la página
- `models/` — las 4 piezas 3D de Teo (STL en base64)
- `teo.html` — la misma página sin la cabecera HTML (versión de publicación)
